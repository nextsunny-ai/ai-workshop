첫 PPT 한 장이 = 6시간 걸렸다

표지 한 장 = 6시간. 일주일 후 = 30분. 한 달 후 = 10분. 그 차이는 = 학습 누적 + 페르소나 + 자료 정리 = 였다. 근데 = 그 모든 게 = "오늘 밤 한 장" 부터 시작한다.

6시간

첫 진짜 결과물은 = PPT 한 장이었다. 회사 IR 자료의 표지였다. 6시간 걸렸다.

문장으로 박으면 한 줄이지만 = 그 6시간은 = 진짜 길었다.

처음 = "표지 한 장 박아줘" 라고 쳤다. AI = 글자만 가득한 화면을 답으로 줬다. "안티 템플릿이라고 했잖아." 라고 = 다시 쳤다. AI = 글자가 조금 줄었지만 = 여전히 = 가운데 정렬 + 회색 배경 + 안 어울리는 폰트. "Pretendard 폰트로." 라고 = 또 쳤다. AI = Pretendard 적용. 근데 = 위계 없음. 모든 글자가 = 같은 크기.

이 사이클을 = 20번 정도 돌았다.

30년 디자인 감각이 있어서 = 다행이었다. "여기 = 위계가 없어" "여기 = 한국어 자간이 너무 좁아" "여기 = 1메시지 원칙 위반" 이런 말을 = 진짜 디자이너한테 하듯이 = AI한테 쳤다.

근데 = 진짜 디자이너랑 다른 게 있었다. AI는 = 안 화낸다. "또 갈아엎어 줘" 해도 = "네" 하고 다시 한다. 밤 3시에 = 갈아엎어도 = 다시 한다. 6시간 동안 = 20번 갈아엎었지만 = AI는 = 같은 톤으로 따라왔다.

그게 = 결정적이었다.

"위계가 없어" — 30년 베이스가 AI한테 박힌다

30년 동안 = CD로 일하면서 = 매일 한 말이 있다. "여기 위계가 없어." "여기 = 메시지가 두 개야. 하나로 줄여." "여기 = 색이 5개야. 3개로." "여기 = 한국어 자간 손봐."

이 말을 = 사람 디자이너한테 했을 때는 = 다음 시안에 = 70% 반영됐다. 사람은 = 자기 취향이 있고, 자기 감각이 있고, 어제 잠을 못 자기도 한다.

AI한테 = 같은 말을 했더니 = 다음 시안에 = 100% 반영됐다. 대신 = 처음 시안의 베이스 퀄리티가 = 사람보다 = 낮다. 사람 = 70 → 80 → 85. AI = 30 → 60 → 75 → 85. 사이클은 더 많이 돌아도, 마지막 도착점은 비슷하다.

그 사이클을 = 잠 안 자고 = 새벽 3시에 = 무한히 돌릴 수 있다는 게 = AI의 진짜 장점이다.

30분 → 10분

첫 PPT 한 장 = 6시간. 일주일 후 = 한 장 = 30분. 한 달 후 = 한 장 = 10분.

뭐가 달라졌나?

1) 프롬프트가 짧아졌다.
처음엔 매번 = 30년 디자인 룰을 = 풀세트로 박았다. 일주일 후 = "30년 CD 베이스로 = 1메시지 = Pretendard = 안티 템플릿" 한 줄이면 됐다. 한 달 후 = 페르소나(= 리안)가 = 그 룰을 항상 기억하고 있어서 = "표지 한 장" 한 마디면 됐다.

2) 자료가 누적됐다.
회사 BI·컬러·폰트·로고 = 다 Drive 폴더에 정리. "이 회사 자료 다 보고 = 표지 한 장" = AI가 진짜 자료 다 보고 한다.

3) 갈아엎는 횟수가 줄었다.
처음 = 20번. 일주일 후 = 5번. 한 달 후 = 1번에 = 다 맞춤.

이게 = 학습 누적이다. AI가 학습한 게 아니라 = 내가 학습했다. 내가 = 톤을 박는 법, 자료를 정리하는 법, 페르소나를 만드는 법 = 배웠다.

그러니까 = AI를 쓰는 거 = AI가 똑똑해지는 게 아니라 = 내가 똑똑해지는 거다.

0과 1의 차이가 = 가장 크다

비프로그래머가 AI 처음 만질 때 = 가장 자주 듣는 질문: "AI한테 시키면 다 되는 거 아니에요?"

대답: "되긴 되는데 = 0에서 1로 가는 게 = 가장 어려워요."

0과 1의 차이 = 1과 100의 차이보다 크다.

첫 결과물이 = 어떻든 = 일단 나오면 = 두 번째는 빠르다. 30분 만에 한 장이 나오면 = 한 장이 = 두 장이 되고, 두 장이 = 한 슬라이드 덱이 된다. 한 슬라이드 덱이 = 한 IR 자료가 되고, IR 자료가 = 투자 미팅이 되고, 투자 미팅이 = 다음 분기 운영비가 된다.

근데 = 0 = 시작 안 한 사람한테는 = 이게 = 다 = 0이다.

이 책의 핵심 메시지

"오늘 밤에 = 한 장만 만들어라."

내일 한 장 더 안 만들어도 = OK. 그 한 장이 = 평생 가는 변화의 = 0과 1의 차이다.

한 줄 결론

6시간 = 30분 = 10분. 그 차이는 학습 누적 + 페르소나 + 자료 정리.
근데 그 모든 게 = "오늘 밤 한 장" 부터 시작한다.

(비프로그래머용 · 준비: Claude Code 설치 끝난 상태)

1단계 — 자료 모으기 (5분)

mkdir -p ~/내회사_자료
# = 회사 이름 폴더 만들기

이 폴더에 = 아래 자료를 = 그냥 던져넣는다.

  • 회사 로고 (있으면)
  • 회사 컬러 (메모장에 "메인 #3A5FCD / 서브 #F5A623" 식)
  • 회사 한 줄 소개
  • 강점 3개

2단계 — Claude Code 켜기 (1분)

cd ~/내회사_자료
claude

3단계 — 한 줄 명령 (10분)

이 폴더 자료 다 읽고 = 회사 IR 표지 슬라이드 = HTML 한 장으로 박아줘.
룰:
- Pretendard 폰트 (CDN)
- 슬라이드당 메시지 1개
- 안티 템플릿 (= 기본 PPT 톤 X)
- 위계 = 제목 1 / 부제 1 / 강점 3
- 색 = 위 컬러
파일 이름 = ir_표지_v1.html

4단계 — 열어서 보기 (5분)

open ir_표지_v1.html
# Mac
# Windows = start ir_표지_v1.html

5단계 — 갈아엎기 (5~10분, 횟수 무제한)

v1 봤어. 너무 빡빡해. = 여백 더 + 제목 더 크게 + 강점 박스 톤 다운.
v2 박아줘. v1 파일 그대로 두고 = v2 새 파일.

→ 옛 버전 = 절대 오버라이트 X (글로벌 룰 17 / 일주일 작업 날린 사고 참조)

첫 페르소나 = 한 줄 SKILL.md

# 내회사 리안 — 디자인 페르소나

## 역할
- 모든 시안·PPT·웹 표지·로고
- 30년 디자인 베이스 = 후진 디자인 X

## 룰
- Pretendard 폰트 강제 (한국어)
- 안티 템플릿 (= 기본 PPT 톤 X)
- 슬라이드당 메시지 1개
- 옛 버전 오버라이트 X (= v1 → v2 새 파일)

EOF

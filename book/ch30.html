DDP 전시장에서 30만원
— 코드 2줄 때문에 ㅋㅋ

인터랙티브 게임 시연 직전 = 한도 차서 = 그 자리에서 30만원 결제. 일인기업 가장 위험한 순간 = 현장 시연 + 한도.

진짜 일어난 일

"내가 처음에 클로드 3만원 쓰다가 = 15만원으로 올리고 = 인터랙티브 게임 개발하고 = 시연하려고 DDP 전시장에 갔는데 = 코드가 하나가 꼬여서 안 돼서 = '몇 줄만 수정하면 됩니다' 하고서 = 한도가 딱 끝난 거야. ㅋㅋ 그래서 결국 = 그 자리에서 = 30만원 결제. 코드 2줄 때문에 ㅋㅋ"

— 대표 본인 발언, 2026-05-13

단계별 사고

단계 1 — 3만원 → 15만원 업그레이드

처음 = Claude Pro = $20/월 (= 약 3만원). 근데 = 메시지 한도가 = 자주 차다. = Claude Max = $100/월 (= 약 15만원) 으로 업그레이드. = 한도 = 5배 풀어짐. = 비프로그래머 = "이제 무제한이겠지."

단계 2 — 인터랙티브 게임 개발 + DDP 시연 약속

DDP (= 동대문 디자인 플라자) 미디어아트 전시 = 인터랙티브 게임 시연. 오프라인 = 현장 = 외부 손님 앞. 사전 테스트 = 잘 됨. = 자신감 = "다 되어 있어. 현장 = OK."

단계 3 — 시연 직전 = 코드 한 줄 꼬임

DDP 전시장 도착. 시연 셋업 = 노트북 연결 = 첫 시도. 코드 한 줄 = 꼬임.

  • 변수명 충돌 또는
  • API 응답 형식 변경 또는
  • 외부 라이브러리 버전 차이

= 5분 = 디버깅 = 못 찾음. = "클로드한테 시키자. 몇 줄만 수정하면 됩니다."

단계 4 — 한도 딱 끝남

Claude한테 = 시킴.

  • 1번 호출 = 200줄 코드 답 = 안 됨
  • 2번 호출 = 다른 접근 = 안 됨
  • 3번 호출 = 더 깊은 디버깅 요청
  • ...
  • 10번 호출 후 = "메시지 한도 초과. 다음 갱신 = 5시간 후."

= 시연 = 5시간 후? = = 손님 앞 = 망신.

단계 5 — 그 자리에서 30만원

대표 = 핸드폰으로 = Anthropic Console 접속. = 추가 크레딧 결제 = $200 (= 약 30만원). = 한도 풀림. = 5분 후 = 코드 2줄 수정. = 시연 = OK.

= = 코드 2줄 = 30만원.

사후 분석

왜 코드 2줄 = 한도 폭주?

옛 사용 패턴:

  • 게임 개발 5일 = Max plan 한도 80% 사용
  • 시연 당일 = 남은 20%
  • 디버깅 시도 10회 = 매번 풀 컨텍스트 (= 게임 코드 전체 + 에러 로그)
  • = 한 번 호출 = 약 30,000 토큰 + 응답 5,000 토큰
  • 10회 = 350,000 토큰
  • = 남은 20% = 다 소진.

= 현장 디버깅 = 가장 토큰 폭주.

극복 = 룰 누적

룰 1) 시연·데모 전 = 한도 미리 확인 (Anthropic Console → Usage)

룰 2) 시연 = 한 단계 위 플랜 + 백업 크레딧 준비

룰 3) 사전 테스트 = 풀세트 (= 시연 당일 변경 최소)

룰 4) "몇 줄만 수정" = 위험한 말 — AI는 = 항상 풀세트 답

룰 5) 현장 = 백업 노트북 + 핫스팟 + 결제 카드 (= 3중 백업)

한 줄 결론

현장 시연 + 한도 = 일인기업 가장 위험한 순간.
비프로그래머 = "AI에게 시키면 다 됨" 환상. 실제 = 시연 당일 = 한도 = 망신·결제.

★ 따라하기 박스 77

시연 전 한도 확인 (= 무조건)

Anthropic Console (https://console.anthropic.com):
1. Settings → Plans & billing
2. Usage = 이번 달 사용량 확인
   - "Messages Used: 1,234 / 5,000" 식
3. 시연까지 = 남은 사용량 ÷ 시연 일수
   - 예: 남은 50% + 시연까지 2일 = 일 25% 가능
4. 시연 당일 = 30% 이상 남아야 안전
★ 따라하기 박스 78

시연 + 백업 크레딧 풀세트

시연 1주일 전:
□ 한 단계 위 플랜 확인 (= Pro → Max 또는 Max → Enterprise)
□ 백업 크레딧 ($50~100) 미리 충전
□ 추가 결제 카드 = 폰에 등록 (= 현장 결제 빠르게)
□ Anthropic Console 로그인 = 폰에 저장

시연 당일:
□ 노트북 풀배터리 + 충전기
□ 백업 노트북 (= 옛 모델 OK)
□ 모바일 핫스팟 (= 와이파이 불안 시)
□ 사전 테스트 = 현장 환경에서 = 1시간 전
★ 따라하기 박스 79

"몇 줄만 수정" 패턴 = 위험

실제로 "몇 줄만 수정"이 = 가능한 경우:
- 변수명 직접 grep → 수정 = OK (= AI 호출 X)
- 옛 로그 확인 = grep → 수정 = OK
- 옛 working 버전 = .bak 있음 → 복구 = OK

AI 호출이 필요한 경우 = "몇 줄" 아님:
- 새 기능 추가 → 풀 호출
- 에러 원인 모름 → 컨텍스트 풀 보내야 함
- API 응답 형식 변경 → 코드 전체 수정

→ 시연 당일 = AI 호출 = 최소화.
→ 옛 버전 복구 + 사전 준비 풀세트.

"현장 시연 + 한도 =
일인기업 가장 위험한 순간."

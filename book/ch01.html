AI라는 거, 처음 만져봤다

30년 영상 만드는 일을 했다. 한국 최초의 여성 VFX 감독. 국무총리 훈장. 황해·포화 속으로·삼국지 용의 부활. 직원 100명·매출 200억 회사. 근데 코드는 한 줄도 못 친다.

그날, 챗GPT를 처음 켰다

나는 30년 동안 영상 만드는 일을 했다. 한국 최초의 여성 VFX 감독이라는 타이틀도 있다. 국무총리 훈장도 받았고, 황해·포화 속으로·삼국지 용의 부활 같은 영화 VFX를 100편 넘게 했다. 직원 100명·매출 200억 회사도 운영해 봤다.

근데 코드는 한 줄도 못 친다. 브라우저 콘솔이 뭔지도 잘 모른다.

그런 내가 챗GPT를 켰다.

처음엔 그냥 신기했다. "써니엔터테인먼트 회사 소개 좀 써줘" 라고 쳤다. 답이 왔다. "오, 이거 뭐지?"

답은 어딘가 어색했다. "잠재력을 보유한 콘텐츠 IP 기반의 종합 엔터테인먼트 기업입니다." 이런 식이었다. 번역투 같고, 영혼이 없었다. 30년 동안 시나리오 작가들 톤·카피라이터 톤·시인 톤 다 봐온 사람한테는 = 한눈에 보였다.

근데도 = 신기했다. 말 몇 마디로 글 한 단락이 나왔다. 어색하긴 했지만, 0에서 어색한 한 단락이 나온 거다. 0과 어색한 한 단락의 차이는 = 어색한 한 단락과 좋은 한 단락의 차이보다 크다.

"더 잘할 수 있을 텐데" — 답답함의 시작

처음 며칠은 자기소개·회사 설명·간단한 메일 같은 거를 시켜봤다. 괜찮긴 했다. 근데 = 30년 디자인·VFX 베이스가 있는 나한테 = "괜찮은 정도"는 = 답답한 정도다.

"슬라이드 한 장 만들어줘" → 글자만 가득한 슬라이드. "메일 한 통 써줘" → "안녕하세요. 저는 ...입니다."로 시작하는 뻔한 메일.

원하는 톤을 정확히 박지 않으면 = 무난한 답. 근데 = 내가 톤을 박을 만큼 = 챗GPT 사용법을 모름.

비프로그래머 + 한국어 화자 + 디자인 베테랑 = 이 조합이 = AI 처음 만질 때 가장 답답함을 느끼는 조합이다. "내가 원하는 거 = 내 머릿속에는 명확 = 근데 = AI한테 박을 = 말이 안 떠올라."

Claude를 만난 날

그러다 Claude를 만났다.

처음엔 비슷한 줄 알았다. 근데 = 길게 쳐도 = 끝까지 따라왔다. 30년 디자인 룰 = 7~8 단락으로 박아도 = 다 흡수했다. "안티 템플릿"·"슬라이드당 메시지 1개"·"Pretendard 폰트 강제" 같은 룰을 길게 쳤는데 = 다 지켰다.

특히 Claude Code라는 게 있었다. 이건 = 채팅창이 아니라 = 내 컴퓨터에 직접 들어와서 파일을 읽고 쓰는 도구다. /SUNNY_TEAM/01_써니엔터/ 폴더 안에 있는 자료 다 보고 = 회사 소개 새 버전 박아 라고 쳤더니 = 진짜 그 폴더 봤고, 진짜 새 파일을 저장했다.

처음 = 진짜 작업 같은 작업이 가능해졌다.

그래도 = 비프로그래머

근데 = 여기서도 = 비프로그래머의 벽이 있었다. Claude Code = 터미널이라는 검은 창에서 돌아간다. 명령어 = 영어 + 기호 + 옵션 = 외계어 같다. 설치도 어려웠다.

처음 = 일주일을 = 설치 + 설정 + 실수만 했다. "이게 안 되는 건 = 내가 못해서일까, 도구가 이상해서일까?" 이 질문을 = 매일 했다.

비프로그래머가 AI 도구를 만지면 = 다 이 질문을 한다. "내가 못해서일까, 도구가 이상해서일까?" 답은 = 둘 다 아니다. 그냥 처음이라 그렇다.

첫 진짜 결과물 = PPT 한 장

며칠 헤매고 = 첫 진짜 결과물이 나왔다. PPT 한 장이었다. 회사 IR 슬라이드의 표지. 30년 디자인 베이스 = 만족할 정도는 아니었다. 근데 = 6시간 걸려서 한 장이라도 = 그게 0과 1의 차이였다.

그 후로 = 매일 한 장씩 = 늘었다. 일주일 후 = 한 장이 = 30분. 2주 후 = 한 장이 = 10분. 한 달 후 = 페르소나라는 걸 만들기 시작했다.

근데 그 이야기는 다음 챕터다.

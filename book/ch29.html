띠링띠링 — API가 이렇게 비쌌다

에이전트 시스템 외부 공유 → 해외결제 청구서 폭주 → 그날 다 중단. 일인기업이 가장 자주 마주치는 사고 = 한 번 폭주 = 회사 망함.

진짜 일어난 일

"완전히 에이전트들 시스템 만들어서 아는 사람한테 뿌렸는데 = 해외결제가 된다고 = 띠링띠링 청구서가 날아오기 시작한 거야. ㅋㅋ 난 API가 그렇게 비싼 줄 몰랐지. 말 몇 마디. 특히 시나리오는 = 기니가 장난이 아닌 거야 ㅋㅋ. 그래서 에이전트를 = 괜히 만들었다 싶어서 = 그날 다 중단도 했었어."

— 대표 본인 발언

에이전트 시스템 = 공유

12명 페르소나 + Oracle 서버 + 텔레그램 봇 = 완성. 신나서 = 아는 사람들한테 = 공유. "우리 시스템 = 한번 써봐. URL 알려줄게."

대표 = API key = 자기 거 박혀 있음. 공유 = 외부 사용자가 = 대표 키로 = LLM 호출.

외부 공유 = 사용자가 자기 토큰

// 공유 SaaS 안에 박을 룰:

// ❌ 옛 = 대표 키 박힘 (= 위험)
const API_KEY = 'sk-ant-...';

// ✓ 새 = 사용자가 자기 키 입력
function getUserKey() {
  let key = localStorage.getItem('user_api_key');
  if (!key) {
    key = prompt('Anthropic API key 입력');
    localStorage.setItem('user_api_key', key);
  }
  return key;
}

// 사용자 키 = 사용자가 비용 부담
const r = await fetch('https://api.anthropic.com/v1/messages', {
  headers: { 'x-api-key': getUserKey() }
});

→ 외부 사용자 = 자기 키 = 자기 비용. → 대표 = 비용 0.

★ 따라하기 박스 75

Prompt Caching = 토큰 90% 절감

import anthropic

client = anthropic.Anthropic()

# 옛 = 매번 풀 컨텍스트
def query_old(question):
    return client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=1024,
        messages=[{
            "role": "user",
            "content": f"{LONG_DOCS}\n\n질문: {question}"
        }]
    )

# 새 = 캐싱 활용
def query_new(question):
    return client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=1024,
        messages=[{
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": LONG_DOCS,
                    "cache_control": {"type": "ephemeral"}  # = 캐싱
                },
                {
                    "type": "text",
                    "text": f"질문: {question}"
                }
            ]
        }]
    )

# 첫 호출 = 풀 비용
# 두 번째 이후 = 캐시 적중 = 90% 절감

→ 시나리오·문서 = 매번 같은 컨텍스트 = 캐싱 무조건.

OAuth Pro vs API 정량제

대표가 자기 사용 = OAuth Pro
- claude.ai/code = $20/월 fix
- 한도: 무제한 messages (= 합리적 범위 안)
- 절제 = OK = 결제 충격 X

대표 + 외부 공유 = 사용자 자기 키
- 외부 사용자 = 자기 OAuth 또는 자기 API key
- 대표 비용 = 0

대표가 외부 워커 운영 = API 정량제 + 알람
- API key + Usage limit ($100/월 등)
- 알람 시 = 즉시 차단
- 캐싱 활용

"일인기업 = API key 외부 공유 X."

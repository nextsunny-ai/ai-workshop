"디자인 한 톤으로" — 한 줄

전체 사이트 = 한 톤 = "디자인 시스템".
없으면 = 페이지마다 톤 달라짐 = 어수선.

  • 폰트 — 제목·본문 = 하나만 (= Pretendard)
  • 간격 — 4 / 8 / 16 / 24 / 32 / 48 px
  • 모서리 — 0 또는 4 (= 둥글둥글 X)
디자인 톤 시키는 법
디자인 시스템 적용해줘:
- 컬러 = 메인 #0A0A0E (다크) + 보조 oklch(0.45 0.12 240) (블루)
- 폰트 = Pretendard
- 간격 = 8의 배수
- 모서리 = 0 또는 4px만
- 그라데이션 / 둥근 카드 / 이모지 = 금지 (안티 템플릿)
